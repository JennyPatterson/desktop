      Sync Across Devices

      Keep state on GitHub Gists so refresh on desktop picks up mobile changes.
      Setup:
      • Create a GitHub personal access token with gist scope.
      • Paste it here and click Save Token.
      • Click Create Shared Sync Link once, then open/copy that same link on each device.
      • Use Sync Now anytime to pull latest changes; edits auto-push when token + sync link are present.
